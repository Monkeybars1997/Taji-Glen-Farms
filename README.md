# Taji Glen Farms

Static website. Deploy index.html, styles.css, site.js and the assets directory together.

After changing Tailwind utility classes, run npm install and npm run build:css. Compiled CSS is committed, so hosting requires no build step.

Content uses the company-provided 2026 investor presentation and crop photographs. Embu County is used for location in place of the earlier Mwea wording. The deck's financial details and confidential PDF are not published. Organic production and outgrower integration are described as goals, not certifications or completed programmes. Garlic is a potential future crop. The photos document chilli, French beans and onions without implying export certification or guaranteed availability.

Contact details are supplied by the director's contact slide. Farm size and stevia acreage reflect the company's 2026 presentation and should be reviewed when operations change.
