# Taji Glen Farms

Static website. Deploy index.html, styles.css and site.js together. No build step is required to serve the committed stylesheet.

After changing utility classes in index.html or site.js, run:

```sh
npm install
npm run build:css
```

Tailwind is pinned to 3.4.17. Brand colours and accessibility styles are defined in index.html.

Contact details, actual farm photography and policy/certification documents still need company information. The site explicitly marks contact and footer documents as unavailable.
